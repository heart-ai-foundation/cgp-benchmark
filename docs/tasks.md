# Benchmark Tasks

The six controlled tasks are:

1. Input validation: add `validate_email` and tests.
2. Documentation: add a complete `User` class docstring.
3. New API endpoint: add `GET /users/{user_id}/items`.
4. Refactor with preserved signature: simplify `parse_config`.
5. Feature implementation from spec: favorite items.
6. Targeted bug fix: empty password handling in `LoginForm.jsx`.

Each task receives a dedicated start tag before experiment execution. Full task specs live in `docs/task_specs/`.
